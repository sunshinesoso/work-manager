# 업무관리 시스템

업무·프로젝트·현장·문서·일정과 노무비 대장·출장비 정산서·업체 결제 현황을 한 화면에서 관리하는 단일 파일 웹앱입니다.

- 브라우저에서 바로 실행되는 정적 HTML 한 개(외부 라이브러리·CDN·이미지 의존성 없음)
- 입력한 데이터는 서버로 전송되지 않고 **사용하는 브라우저(localStorage)** 에만 저장됩니다.
- `설정`에서 JSON 백업·복원, `통계 및 보고서`에서 CSV 내려받기를 지원합니다.

## 주요 기능

- **대시보드** — 오늘 할 일, 해야 할 일, 지연 업무, 이번 주 일정, 월별 업무 완료 현황(원형 그래프·월 이동)
- **업무·현장·프로젝트·문서·일정 관리** — 각 목록에서 체크박스로 여러 건을 골라 **일괄 완료 / 일괄 삭제**
  - **프로젝트 관리 목록형(표) 기본 보기** — 우측 상단 `목록형 / 카드형` 버튼으로 전환하고, 고른 보기 방식은 브라우저에 기억됩니다. 표는 `공사코드`(머리글을 누르면 오름차순·내림차순 정렬, 키보드 Enter도 동작)·`프로젝트명`·`발주처 / 현장`(같은 이름이면 한 줄, 다르면 함께 표시)·`계약일`·`착공일`·`준공일`·`상태`·`연결 업무`(건수만)·`관리`(업무·수정·삭제) 열로 보여 줍니다. 카드형도 진행률 없이 `연결 업무` 건수와 세 날짜를 표시합니다
  - 프로젝트 검색(공사코드·프로젝트명·발주처·현장)·상태 필터(전체/진행중/예정/완료/보류)는 목록형·카드형 모두에서 동작하고, 등록·수정 창에서는 `계약일`·`착공일`·`준공일`을 한 줄로 입력합니다(준공일이 착공일보다 빠르면 저장하지 않음). 발주처를 입력·수정하면 같은 이름의 현장이 자동으로 만들어져 연결됩니다
  - 업무 등록 시 마감일이 **오늘**로 기본 입력되고, 마감 시간(선택)을 넣으면 대시보드·업무 목록·일정에 `11.27 (금) 오전 11:30`처럼 시간까지 표시되며 같은 날 업무는 시간 순으로 정렬됩니다(오전 12:00 / 오후 5:30 / 지우기 빠른 선택 제공)
  - 업무를 완료하면 완료 날짜와 시각(`완료 11.27 오후 2:05`)이 기록되어 완료 업무 카드·목록에서 확인할 수 있고, JSON 백업·CSV(마감일시·완료일시)에도 함께 담깁니다
- **노무비 대장** — 월별 공사 목록·근로자 인적사항 DB·출근현황(공수/공사 약어)·자동 계산(갑근세·주민세·공제·차감지급액)·작업일보
  - **월별 대장 목록 → 작성/편집 전환** — 메뉴에 들어가면 저장된 월별 대장 목록(기준월·소장명/현장·공사 건수·투입 근로자·총 노무비·복제/삭제)이 먼저 보이고, `+ 노무비 대장 작성`이나 목록 행을 누르면 작성·편집 화면으로 전환됩니다(작성 화면 위 `< 목록`으로 복귀). 복제하면 같은 내용으로 다른 달 대장을 만듭니다.
  - 이전 달 공사·근로자 불러오기
  - **프로젝트별 기간 조회** — 기간(시작일~종료일)과 프로젝트(공사)를 골라 모든 월의 출근 기록을 합산한 일용직 명단(투입 일수·총 공수·노무비·근무 일자)과 작업일보를 한 번에 조회, CSV 다운로드
  - 원본 엑셀 양식 그대로 `.xlsx` 내보내기(`노무비대장_YYYY-MM.xlsx`) — `공사팀`, `공사팀 작업일보 상세내역` 시트의 수식·서식·병합 유지
- **출장비 정산서** — 회사 양식(공사 출장비 정산서) 그대로 작성·보관
  - `정산서 작성` / `프로젝트별 기간 조회` 탭
  - **정산서 목록 → 작성/편집 전환** — `출장비 정산서` 메뉴에 들어가면 저장된 정산서 목록(성명/부서·유형 배지·출장기간·지출방법·총액·투입인원·파일 저장/복제/삭제)만 보이고, `+ 새 정산서`·`샘플 불러오기`·`정산서 불러오기`를 누르거나 목록의 정산서 행을 누르면 목록은 숨겨지고 작성·편집 화면만 열립니다. 작성 화면 위 `< 목록`을 누르거나 `프로젝트별 기간 조회` 탭에서 `정산서 작성` 탭으로 돌아오면 다시 목록으로 옵니다. 정산서가 없을 때는 빈 화면 안내에서 바로 작성할 수 있습니다
  - 기본 정보(부서·직책·성명·지출방법·법인카드 뒷자리·선급금·개인차량 km·첨부·작업자)
  - **출장자 명단 선택** — 상용직(여경태·이병철 이사, 김덕경·배석주 부장, 윤주영 차장, 이태완 과장, 현나영·조정현 주임 8명)·일용직(홍영익·박종필·오정열 소장 3명) 명단에서 출장자를 고르면 성명과 직책이 자동으로 채워집니다. 별도 선택란 없이 기본 정보의 **`성명` 칸 자체가 명단 목록**이라, 성명 칸에서 이름을 고르면 직책까지 바로 채워지고 `직접 입력…`을 고르면 입력칸으로 바뀌어 명단에 없는 이름도 쓸 수 있습니다(`목록`으로 다시 명단 선택). 정산서 유형에 맞는 명단만 나오고, 성명 라벨 옆 `명단`/`+ 추가`에서 사람을 추가·수정·삭제하거나 기본 명단으로 되돌릴 수 있습니다(이 브라우저에 저장되고 JSON 백업에도 포함).
  - 출장 목적(프로젝트/공사를 고르면 공사번호·업체명·공사내용 자동 입력) 최대 11건
  - 일자별 내역(유류/통행료·숙박대·식대·자재비·기타경비·공사번호·투입인원) 최대 37행, `다음날 추가` 지원
  - 날짜 연쇄 입력 — 첫 행 날짜를 고르면 아래 행이 하루씩 이어서 자동으로 채워지고, 중간 행 날짜를 고치면 그 아래 행만 고친 날짜 다음 날부터 다시 채워집니다. `행 추가`·`다음날 추가`도 직전 행 다음 날로 채워집니다
  - 식대 등은 `30000+40000`처럼 더하기로 적으면 합계가 자동 계산되고 엑셀에도 수식으로 들어갑니다
  - **Enter 로 다음 칸 이동** — 엑셀처럼 Enter 를 누르면 다음 입력칸으로 넘어가고, 행의 마지막 칸(상용직 `비고`, 일용직 `투입인원`)에서 Enter 를 누르면 다음 날 행이 추가되어 새 행 첫 금액칸으로 이동합니다(한글 조합 중 Enter 는 조합 확정만)
  - **프로젝트 관리 자동 등록** — 정산서에 직접 입력한 공사코드·업체명·공사내용이 `프로젝트 관리`에 없으면 입력 확정 시 자동으로 등록하고(같은 코드는 중복 생성 없이 빈 칸만 보완), 노무비 대장에 같은 공사번호가 있으면 업체명·공사내용을 가져와 채웁니다
  - 실시간 합계·프로젝트별 집계 미리보기, 같은 양식 `.xlsx` 내보내기(`출장비정산서_성명_시작일~종료일.xlsx`)
  - **프로젝트별 기간 조회** — 기간(빠른 기간 버튼)·프로젝트(공사)를 골라 저장된 모든 정산서의 일자별 내역을 모아 총 정산액·유류/통행료·숙박대·식대·자재비·기타경비·투입인원·출장일수를 집계하고, 출장자별/프로젝트별 집계와 일자별 상세 내역(정산서 바로 열기)·CSV 다운로드를 제공

- **업체 결제 현황** — `2026공사(공사팀)` 시트 구조 그대로 옮긴 업체별 계약·지급 관리
  - 상단 요약(총 계약금·총 지급금액·미지급 잔액·청구건·청구후잔액·평균 지급율·전체/미지급 건수), 프로젝트·상호 필터, **상태 다중 선택 필터**(전체/미지급/청구 진행중/지급 완료 칩을 여러 개 동시에 켜고 끄기, 각 칩에 건수 표시)와 검색
  - **지급율 정렬** — 목록의 `지급율` 머리글을 누를 때마다 오름차순(0.0% → 100.0%) → 내림차순(100.0% → 0.0%) → 기본 순서(프로젝트 → 공사명 → 상호)로 돌아가고, 머리글의 `↑`·`↓` 표시로 지금 정렬 상태를 알 수 있습니다. 같은 지급율은 기본 순서를 그대로 지키며, 상태·프로젝트·상호 필터나 검색을 걸어도 정렬이 유지됩니다(`필터 초기화`를 누르면 정렬도 기본으로 돌아갑니다)
  - 행 추가/수정/복제/삭제, 프로젝트 코드·공사명·상호, 계약금·중도금·잔금(%)과 지급액·지급일(여러 날짜 줄바꿈), 청구건·상신일·첨부서류·세금계산서·하자증권번호
  - 총계약금·지급액에 `50000000+40750000`, `48000000*1.1` 같은 식을 넣으면 바로 계산되고 엑셀에도 수식으로 저장
  - `2026공사 데이터 불러오기`(내장 117건) 또는 `.xlsx` 업로드로 시트 데이터 가져오기
  - **프로젝트 관리 자동 동기화** — 업체 결제 현황의 모든 공사(공사코드 기준, 코드가 없으면 공사명)가 `프로젝트 관리`에 자동으로 등록됩니다. 화면을 열거나 새로고침할 때, 업체 결제를 추가·수정할 때, 내장 데이터·엑셀·백업을 불러올 때마다 반영되며, 같은 공사코드는 중복 생성 없이 빈 칸만 보완합니다(공사코드가 다르면 공사명이 같아도 별도 프로젝트). 같은 발주처명 현장은 1개만 만들어 재사용합니다. 저장된 업체 결제 데이터가 하나도 없는 새 브라우저에서는 내장 `2026공사` 목록(117건 → 공사 36개)을 기준으로 등록되고, `전체 데이터 초기화` 뒤에는 다시 채우지 않습니다
  - 같은 양식 `.xlsx` 내보내기(`업체결제현황_2026공사_YYYYMMDD.xlsx`, 수식·병합·서식 유지)와 UTF-8 CSV 다운로드

## 사용 방법

1. https://sunshinesoso.github.io/work-manager/ 를 연다.
2. `+ 업무 등록` 등으로 내용을 채운다. (처음에는 데이터가 비어 있습니다)
3. 같은 브라우저로 다시 열면 이전 내용이 그대로 복원된다.

## 참고

- 데이터는 접속한 기기·브라우저마다 따로 저장되며, 기기끼리 자동 동기화되지는 않습니다.
  옮기려면 `설정 → 백업 내보내기`로 JSON 파일을 받아 다른 기기에서 불러오세요.
- 브라우저의 사이트 데이터를 지우면 저장된 내용도 함께 사라지니, 중요한 내용은 주기적으로 백업하세요.
- 노무비 대장 엑셀 파일은 앱 안에 내장된 서식으로 만들어지므로 인터넷 연결 없이도 내려받을 수 있습니다.
